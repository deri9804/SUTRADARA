      Pengaturan Gemini API Key

      Gunakan API Key Google AI Studio Anda sendiri (Gratis)

      Cara Ambil API Key Gratis: Buka AI Studio
      1. Buka aistudio.google.com/apikey dan login akun Google.
      2. Klik tombol "Create API key".
      3. Salin (copy) kunci yang didapat, lalu tempel pada kolom di bawah ini.

      💡 Kuota gratis Google: 1.500 request/hari dan di-reset otomatis setiap 24 jam. Kunci Anda tersimpan aman hanya di browser perangkat ini.

      Integrasi n8n Video Pipeline

      Hubungkan Trendora AI ke n8n untuk render video otomatis

      Cara Menghubungkan ke n8n:
      1. Buka workflow di n8n lu, tambahkan trigger node "Webhook".
      2. Atur HTTP Method menjadi POST.
      3. Salin Test URL (saat testing) atau Production URL (jika workflow sudah Active).
      4. Tempelkan URL tersebut pada kolom di bawah ini dan klik "Simpan Webhook URL".

      🎬 Paket Data yang dikirim: Gambar Tiap Scene (Base64), Video Motion Prompt, Dialogue, Durasi, dan Aspek Rasio. Siap diteruskan ke Kling / Runway / Luma / Replicate di n8n!
